# ТЗ: сверка ментальной модели с текстом — чего не хватает в модели

Дата: 2026-11-16T2210
Роль захода: аналитик
Заказчик: пользователь

## Зачем

В ролике есть скелет — `v4/ментальная-модель.md`, список опорных точек со выписками из текста. Заказчик заметил, что список тоньше речи: в тексте смыслов больше, чем заведено в модель. Нужно найти всё, чего в модели нет.

## Задача

Сравнить модель с речью глав `v4/0*.md` и с первоисточниками `chapters/`, и выдать три перечня:

1. **Смыслы и тезисы, которые есть в речи, но не заведены в модель как опорные точки.** Для каждого — дословная цитата из текста и глава.
2. **Точки модели, где описание тоньше, чем то, что сказано в тексте.** То есть в модели одна фраза, а в речи развёрнутый ход с примерами или числами. Для каждой — цитата и глава.
3. **Смыслы из первоисточников `chapters/`, которых нет ни в речи, ни в модели.** Для каждого — цитата из первоисточника и его файл.

Судить по смыслу, а не по совпадению слов: если мысль в модели изложена другими словами — она заведена, писать о ней не надо. Интересует только то, чего нет.

## Чего не делать

- Не считать слова и не приводить числа слов как меру: «толще/тоньше» — это про смысл, а не про объём.
- Не править текст, модель, ссылки: только чтение. `git commit` и `git push` не запускать.
- Не пересказывать своими словами вместо цитат: в перечнях — дословные фразы.

## Формат артефакта

Файл `.factory/goals/2026-11-16T2210-sverka-modeli.md` с тремя разделами по перечням выше. В каждом пункте: смысл своими словами в одну фразу, под ним — цитата и глава (или файл первоисточника).

## Что должно быть в отчёте

- Три раздела, каждый с перечнем пунктов либо явным «не найдено».
- По каждому пункту — цитата из текста или из первоисточника.
- Без числовых мер и без вердиктов: это разведка, решение принимает автор.
