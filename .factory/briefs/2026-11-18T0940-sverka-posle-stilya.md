# ТЗ: сверка нового текста v4 с первоисточниками после стилевой переработки

Дата: 2026-11-18T0940
Заказчик: пользователь

## Зачем

Все тринадцать глав `v4/` переписаны на живую речь. Ментальная модель сверена с текстом, но её выписки сняты с самого текста: это проверка на дрейф замысла, а не на верность источникам. Нужна независимая проверка: что из `chapters/` дошло до нового текста, что исказилось, что потерялось, и что в тексте появилось сверх источников.

## Задача

Прочитать первоисточники `chapters/` и текущие главы `v4/0*.md` и выдать по каждой главе:

1. **Сохранено** — мысль источника, которая в тексте есть (дословно или пересказана под речь).
2. **Пересказано** — мысль есть, но подана другими словами, на слух; назвать одной строкой, что именно изменилось в подаче.
3. **Искажено** — смысл сдвинут, сужен или расширен против источника: цитата источника и цитата текста.
4. **Потеряно** — мысль источника, которой в тексте нет: цитата источника.
5. **Добавлено сверх источников** — заметное утверждение текста, которого нет в источнике: цитата текста и класс (история / индустрия / личный опыт).

Судить по смыслу, а не по совпадению слов. Пересказ — не потеря. Новая формулировка той же мысли — не находка.

## Вне scope

- Не править текст, модель, ссылки: только чтение.
- Не считать слова, знаки и проценты.
- Не сверять факты с сетью: сети нет. Факты проверены отдельно в `v4/ссылки.md`, сюда не лезть.
- `git commit`, `git push` не запускать.

## Как читать дубли

В `chapters/` есть две версии главы 3.3 и две версии блока 7.5. Брать ту версию 3.3, что совпадает по составу с `v4/03c-dva-rezhima.md` (в ней есть позиционное кодирование, JEPA, блок «Рефлексы», ModernBERT). Версии 7.5 побайтово идентичны, брать любую.

## Формат отчёта

`.factory/goals/2026-11-18T0940-sverka-posle-stilya.md`

- Таблица по главам: сохранено / пересказано / искажено / потеряно.
- Затем раздел «Требует решения автора»: только искажения, потери и добавки, которые действительно меняют смысл. Каждый пункт: цитата источника, цитата текста, в чём расхождение.
- В конце: одна страница «что делать» — списком, без воды.

## DoD

1. В отчёте есть таблица по всем тринадцати главам. Signal: файл отчёта, строки всех глав.
2. Каждый пункт раздела «Требует решения автора» содержит две цитаты: из источника и из текста. Signal: файл отчёта.
3. Текст, модель и ссылки не изменены. Signal: `git status` показывает те же изменённые файлы, что до запуска.
