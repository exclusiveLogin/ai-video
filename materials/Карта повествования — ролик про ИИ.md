## Структура блоков по порядку

### 0. Интро [ч]
Благодарность за прошлый ролик → хайп вокруг vibe-coding → тревога инженеров → заявка: «сугубо инженерное мнение, 20 лет в IT».
Адресация: всем, кто использует ИИ; главное — разработчики и архитекторы.
**Обещание:** «разработчики и архитекторы увидят то, о чем молчат создатели закрытых коробок вроде Cursor или Claude» — ЗАКРЫТО гл. 8.

### 0.1 Дорожка повествования [ч]
Анонс маршрута: базис → современная разработка с ИИ (DSL, OpenSpec, SDD, граф-инжиниринг) → взгляд в будущее → личные советы.
Ремарка: «ролик не образовательный, не истина в последней инстанции».

### Глава 2. ТЕОРИЯ [р — почищен]
- **2.1 Классика vs ML** — кот/собака/лиса/корги → комбинаторный взрыв (перечень ML-подходов снят при чистке).
- **2.2 Наивный Байес на спаме** — «кредит 70% спама» → закономерность сама.
- **2.3 Метафора банки** — хаос фракций → стратифицировать. «Кто в теме — мотайте».
- **2.4 Три принципа ML** — гранулярность, дифференцируемость (X−19=0, ресторан), итеративность (GPU, локальный минимум).
  - Амбер-строка про вендора — из текста вынесена (кандидат: гл. 8 или финал).

### Глава 3. АРХИТЕКТУРЫ [н] (номер предположителен)
- **3.1 Эмерджентность: почему одного слоя мало** — Розенблатт → Минский/Паперт → backprop 1986 → Цыбенко/Хорник → снежинка → латентное пространство → Павлов → эмерджентность + банка (финальное появление).
  - Долг: оговорка «Цыбенко — представимость ≠ обучаемость»; МакКаллок/Питтс; «объяснение Кугэна».
- **3.2 От MLP к Трансформеру** — ограничения MLP («Мама мыла раму») → RNN → LSTM → GRU → стопор → 2017 Self-Attention, «Рыжая лиса остановила» → параллельность, LLM → O(n²), контекстное окно.
  - Positional Encoding — ЗАКРЫТО (внесен в 3.3). Конструктор слоя — решение: не возвращать.
- **3.3 Два принципа / Трансформер захватывает мир / Итог главы** — энкодер/декодер/гибрид → каузальная маска + позиционное кодирование → денойзинг, U-Net/DiT → энкодеры латента (T5, CLIP, ControlNet) → Sora, Suno → «база одна, провода припаяны» → мостик «что этот инструмент не может?».
  - Коллизия «Три/Два принципа» — предложение: «Два режима».

### Глава 4. СТЕНА: ПОЧЕМУ ИИ НЕ СТАНЕТ БОГОМ [н]
Интерполяция vs экстраполяция → «ИИ слеп» → Grounding Problem → Планк: смена базиса → LLM реактивна vs байесовский фильтр → «заморожена» → галлюцинации имманентны → RLVR/RLHF: песочница, «щелчок по носу», дрессировка → «заперт в нашей культуре, зеркало прошлого» → тизер «а что если сломать?».
**Внесено:** критик-дискурс и «мы тоже скрещиваем смыслы» (сжато, оригинал стр. 15–17 PDF). «Цифровой памятник» внесен.

### Глава 5. R&D: ГДЕ ИДЁТ ВОЙНА [н]
Рекап стены → 5 направлений: SEAL/self-referential matrices; сон как гиперпараметр; SAE + activation steering; TTT (TEMPO, AIME); SNN + мемристоры → самое радикальное (колбэк к Планку) → «хрипко, дорого, ломается» → «зеркало или перестройка зеркала» → тизер «рынок горит».
**Выброшено из сверхразум-блока (статус на 2026-11-13):** 2 пути к сверхразуму — ВЫБРОШЕНО ОКОНЧАТЕЛЬНО (подтверждение автора 2026-11-13, тема закрыта тейком двух путей в гл. 4); вязкость — ЗАКРЫТО (гл. 4); Оракул — ЗАКРЫТО (переосмыслен, в финале); риски самомутации — частично прикрыто занозами в гл. 5; метаконтроллеры — на обсуждении.

### Глава 6. КОДИНГ: СМЕРТЬ СИНТАКСИСА [н]
Стык-рекап гл. 4–5 → промпт как язык → код = черный ящик/бинарник → «конец скриптов» → язык как ментальная структура → архитектура = долгосрочная гипотеза → «не заменяет инженера» → вижен → синтаксические «лингвисты» → инженер-архитектор → смерть инди-киллеров → SDD/OpenSpec: сеть = компилятор → harness-окружения → «у них летает — у нас нет» → код = hash → оператор-транслятор = соучастник деградации → вижен, «капитан корабля» → «агент уйдет в саморефлексивный бред» → тизер «Cursor и „сделай хорошо" — путь в никуда».
**Выброшено (решить):** кризис авторства; опровержение «агент-компилятор» (мультиагентность); Suno/композиторы; вымывание редких языков; джуны/кривая обучения/выгорание/«не будет ли то же с людьми?» — теперь кандидаты ТОЛЬКО в финал.

### Глава 7. ФАБРИКА: МУЛЬТИАГЕНТНЫЙ КОМБАЙН [н]
Стык: «говорили про SDD и капитана корабля…» → картина рынка: Claude Code/Cursor + скиллы + MCP → «промптим, ревьювим, коммитим»; зрелые: SDD, DoD, но ревью глазами → **Context Rot**: «один гений = архитектор + кодер + тестировщик + техпис», мега-агент теряет идею, «саморефлексивный бред», «рюкзак один» → **комбайн (Hermes, Pi, ACP):** ролевой граф → бриф (.factory/briefs/) → отчёт о целях → **Аудитор:** DoD, PASS с сигналами (grep, строки) → адверсариальные проверки (CSS-специфичность, animationend + prefers-reduced-motion, git diff + package.json) → артефакты: бриф/код/отчёт/аудит, FAIL + рекомендации → Observability: Phoenix + OpenTelemetry → «я строю фабрику» → тизер «кто владеет инструментами? Ты или вендор?».
**Закрывает:** интро-обещания «граф-инжиниринг» и «тулинг».
**Тон:** «ты» → «вы» — ПОЧИНЕНО.

### Гл. 4: RL как козырь критика — внесено и отвечено (2026-11-13, по замечанию автора)
Автор пояснил: «физически не может пойти на ухудшение метрик» — речь про датасетное обучение; RL же преподносится как альтернатива наравне с идеей «RL-AGI, который может открыть свою физику». Три правки:

## Второй мозг — предложения (на выбор, не все сразу)

1. **Латентный капитал.** Твои артефакты (брифы, аудиты, логи, ADR) — актив, который накапливается и переживает смену моделей. Модели меняются каждые полгода — .factory остаётся. Модель — расходник, артефакты — капитал.
2. **Личная модель + личная база.** Fine-tune локальной мелкой модели (DeepSeek/Qwen) на своём коде и заметках. Second brain как RAG поверх личной базы знаний.
3. **Агент-библиотекарь.** Агент, живущий в твоём knowledge base и сам его актуализирующий (как скиллы, но open source).
4. **Человек как стелс-агент в трассе.** Врываться в reasoning trace мультиагентной цепочки, когда этого требует безопасность или задача. (Связано с блоком «вмешательство в трассы» гл. 7.)
5. **Люфт агентов как фича.** Недетерминизм = пространство для divergent thinking, если контролировать метриками. Не баг, а источник вариативности.
6. **Продукт-мышление.** Код — расходник, продукт — цель. (Уже в гл. 6, кандидат на усиление.)
